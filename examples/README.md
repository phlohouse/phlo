# Phlo examples

Complete lakehouse examples live in [`lakehouses/`](lakehouses/). They are standalone projects, not one shared environment. Open the [documentation catalogue](../docs/guides/example-lakehouses.md) to choose by use case, or read [`lakehouses/catalog.json`](lakehouses/catalog.json) for machine-readable discovery.

Run commands from the selected example directory and follow its README. Do not assume that the root lock file, service profiles, ports, or expected outputs apply to every example.
