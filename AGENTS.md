# Repository guidance

- **Planning or locating a change:** read `docs/contributing/engineering-map.md` for ownership, authorities, and generated-file boundaries.
- **Choosing verification:** read `docs/contributing/verification-matrix.md`; `make check` is a baseline, not the complete test suite.
- **Changing a package:** read `packages/AGENTS.md` and any nearer `AGENTS.md`.
- **Changing the agent app:** read `apps/phlo-agent/AGENTS.md`.
- **Changing Observatory:** read `packages/phlo-observatory/AGENTS.md`.
